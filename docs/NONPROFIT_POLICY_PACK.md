# Nonprofit Organization Policy Pack

The nonprofit pack applies donor and program requirements through a nonprofit capability profile while keeping the shared Alloc-X payment, Approval Layer, signing, and receipt controls intact.

It evaluates program allocations, cost categories, active donor mandates, reporting periods, evidence requirements, available program capacity, and allocation expiry. Every assessment is deterministic and returns `ALLOW`, `REVIEW`, or `DENY` with reason codes.
