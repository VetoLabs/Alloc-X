# Allocation Agent

The Allocation Agent turns a bounded treasury instruction into a draft payment intent or an evidence request. It can resolve a beneficiary, ask for missing evidence, draft an intent, and explain the applicable policy. It cannot access credentials, private keys, signing, direct ledger submission, arbitrary network calls, policy publication, or direct database access.

Its session journal is durable locally. A future language-model interpreter may replace the strict command interpreter, but it must emit the same validated command shape and can never receive a capability beyond the typed server-side tools.
